#Todo List React#
Todo List приложение на React + TypeScript. Позволяет создавать, редактировать и помечать задачи как выполненные. Реализована функциональность разделения активных и завершённых задач. Все данные сохраняются в локальном хранилище браузера.  
  
##Технологический стек:  ##
  
**Frontend:** React 19, TypeScript  
**Управление состоянием:** Zustand (с persist middleware)  
**Сборка:** Vite  
**Стили:** SCSS Modules  
**Хранилище:** LocalStorage  
**DevTools:** Zustand DevTools  
  
**Ключевые особенности:**  
-Полнофункциональное CRUD (Create, Read, Update, Delete/Toggle)
-Сохранение данных между сеансами браузера
-Разделение активных и завершённых задач
-Inline редактирование задач
-Типизированное хранилище данных
